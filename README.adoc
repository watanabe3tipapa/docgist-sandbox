= DocGist

DocGist は AsciiDoc(.adoc)を紹介・アピールするためのコンテンツサイトです。
特に「生成 AI との親和性」を主軸に据え、構造が明示的な AsciiDoc が AI と共存しやすい形式であることを解説しています。

.README (English): https://github.com/asciidoctor/docgist-sandbox/blob/main/README.en.adoc[README.en.adoc]

== 概要

* ランディングページ(LP)+ チュートリアル + プレイグラウンドで構成
* AsciiDoc の構文解説(アドモニション・テーブル・include など)
* Monaco エディタで .adoc を書き、Asciidoctor でリアルタイムに HTML 変換できるプレイグラウンド
* 日本語(ja)/英語(en)の 2 言語対応

== 技術スタック

* SSG: https://astro.build[Astro](Node 一元管理)
* .adoc 変換: https://github.com/asciidoctor/asciidoctor.js[Asciidoctor.js](npm `asciidoctor`)
* エディタ: https://microsoft.github.io/monaco-editor/[Monaco Editor]
* デザイン: Neo Brutalism(素の CSS / CSS 変数。フレームワーク不使用)
* i18n: Astro の i18n ルーティング
* 公開: GitHub Actions → GitHub Pages

== ページ構成

* `/`: LP(日本語)
* `/en`: LP(英語)
* `/what-is-asciidoc`: AsciiDoc 解説
* `/playground`: ライブ変換プレイグラウンド(左: エディタ / 右: 変換結果)

== ローカル開発

前提: Node.js 22 以上

[source,shell]
npm install
npm run dev

ビルドとプレビュー:

[source,shell]
npm run build
npm run preview

== デプロイ

`main` ブランチへの push で GitHub Actions(`.github/workflows/pages.yml`)がビルドし、GitHub Pages へ公開します。
`base: /docgist-sandbox` 配下へ配信されるため、サイトのアセット参照は `src/lib/link.ts` 経由でベースパスを解決しています。
