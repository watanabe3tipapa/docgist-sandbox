= DocGist

DocGist は AsciiDoc（.adoc）を紹介・アピールするためのコンテンツサイト（サンドボックス）です。
特に「生成 AI との親和性」を主軸に据え、構造が明示的な AsciiDoc が AI と共存しやすい形式であることを解説しています。

.README (English): README.en.adoc[README.en.adoc]

== 概要

DocGist は以下で構成される静的コンテンツサイトです。

* ランディングページ（日本語/英語）
* AsciiDoc の解説ページ
* Monaco エディタを用いたライブ変換プレイグラウンド（エディタで編集すると右側に Asciidoctor による HTML がリアルタイム表示されます）

サイトのデザインはフレームワークを使わない素の CSS（Neo Brutalism）を採用しています。公開版のランディングページはリポジトリの GitHub Pages にてホストされています（プロジェクトのホームページ: https://watanabe3tipapa.github.io/docgist-sandbox/）。

== 主な内容

* AsciiDoc の構文解説（アドモニション、テーブル、include など）
* ランディングページ（日本語 / 英語）
* Playground: Monaco Editor で .adoc を編集し、Asciidoctor.js による変換結果を確認
* 多言語対応（日本語 / 英語）

== 技術スタック

* SSG: https://astro.build[Astro]（Node 一元管理）
* .adoc 変換: https://github.com/asciidoctor/asciidoctor.js[Asciidoctor.js]（npm パッケージ: asciidoctor）
* エディタ: https://microsoft.github.io/monaco-editor/[Monaco Editor]
* デザイン: Neo Brutalism（素の CSS / CSS 変数、フレームワーク不使用）
* i18n: Astro のルーティング機能を利用した多言語構成
* 公開: GitHub Actions → GitHub Pages

== ページ構成（主要ルート）

* / : 日本語ランディングページ
* /en : 英語ランディングページ
* /what-is-asciidoc : AsciiDoc 解説ページ
* /playground : ライブ変換プレイグラウンド（左: エディタ / 右: 変換結果）

== ローカル開発

前提: Node.js 22 以上（package.json の engines に準拠）

[source,shell]
----
npm install
npm run dev
----

開発サーバーを起動するとローカルでサイトを確認できます。スクリプトは package.json に定義されています（dev, build, preview）。

== ビルドとプレビュー

[source,shell]
----
npm run build
npm run preview
----

これらのコマンドは package.json のスクリプトに準拠しています。

== デプロイ（運用）

リポジトリの `main` ブランチへの push により GitHub Actions がビルドし、GitHub Pages へ公開される構成です（既存 README にて `.github/workflows/pages.yml` を参照する記載があります）。
サイトは `base: /docgist-sandbox` の配下へ公開されるため、アセット参照はベースパスを考慮して解決される設計になっています（既存 README にて `src/lib/link.ts` 経由でベースパスを解決している旨の記載があります）。
